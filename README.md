# silicon

本仓库为 silicon 通用基础库源码（分支 `leo/dev`）。

> **协作、接入、记忆与进度全部承载在乐享团队知识库「silicon」**（通过乐享连接器访问），
> 仓库内**不再维护** `memory/`、`progress/` 等协作文档与代码仓库接入细节。

## 从这里拿全部信息(代码获取/接入/记忆/进度)

新成员或新会话接入本工程，**先读乐享团队知识库「silicon」**，其内容为唯一权威、集中维护：

- **代码获取与仓库接入**（仓库地址 / `leo/dev` 分支 / 工蜂认证 / 克隆命令）：见乐享 `memory/` 的 **repo** 页。
- **记忆**（工程稳定知识 / 约定 / 踩坑，按主题拆分）：入口为乐享 `memory/` 的 **MEMORY** 页（主题索引），
  按需读 `repo` / `build` / `verify` / `adr` / `conventions` / `collab` 页。
- **进度**（当前进度快照 / 变更日志 / 待办）：见乐享 `progress/` 的 **PROGRESS** 页。

每轮协作纪律（轮前读记忆+进度、轮中更新、轮后同步回乐享）以乐享 `memory/` 的 **collab**、**conventions** 页为准。

> 记忆 / 进度 / 接入说明仅存于乐享知识库,不在本仓库内重复,避免多处不一致。
