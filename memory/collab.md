# 6. 团队协作要求

**每位成员在每轮修改完成后，必须同步两份工作文档：**
1. **进度 PROGRESS.md**（仓库 `progress/PROGRESS.md` + 项目资产 `progress/PROGRESS.md`）——把本轮进展、提交 hash、待办登记进"变更日志"，让下一位成员可续接。
2. **记忆**（仓库 `memory/` + 项目资产 `memory/` 同构拆分）——把本轮产生的稳定知识（新约定/新架构要点/新踩坑）沉淀进对应主题文件。

> 具体执行路径与"同步到项目资产"的操作方式，以项目根 `README.md`"团队协作要求"一节为准。
> 记忆文件组织：本目录（`memory/`）按主题拆分，仓库 `leo/dev` 与本项目资产各持一份同构副本、互为镜像；无根级单文件权威副本。
